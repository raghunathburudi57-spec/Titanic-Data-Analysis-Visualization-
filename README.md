# 🚢 Titanic Survival Analysis

## 📌 Project Overview

This project analyzes the **Titanic passenger dataset** using **Python and Exploratory Data Analysis (EDA)**. The objective is to explore the dataset, perform **data cleaning and preprocessing**, conduct **statistical analysis**, and visualize important insights to understand the factors that influenced passenger survival.

The project focuses on analyzing important features such as **gender, age, passenger class, survival status, and other passenger information** to identify patterns and relationships in the dataset.

## 📊 Dataset

* **Dataset Name:** Titanic Dataset
* **Source:** Titanic Passenger Dataset
* **Analysis Type:** Exploratory Data Analysis (EDA)

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / Google Colab

## 📈 Project Tasks

* Imported and explored the Titanic dataset
* Examined dataset structure, data types, and statistical information
* Identified and handled missing values
* Performed **data cleaning and preprocessing**
* Conducted **descriptive statistical analysis**
* Analyzed passenger survival patterns
* Compared survival rates based on **gender**
* Analyzed the relationship between **passenger class and survival**
* Performed **age-based survival analysis**
* Created different age groups for better analysis
* Identified important patterns and trends in passenger survival
* Performed **data visualization** to represent insights clearly

## 📊 Data Visualizations

The project includes graphical analysis and visualizations such as:

* Survival distribution charts
* Gender-wise survival analysis
* Passenger class-wise survival comparison
* Age distribution analysis
* Age group survival comparison
* Bar charts
* Histograms
* Statistical visualizations

## 🔍 Key Insights

The analysis helps identify the major factors that influenced survival during the Titanic disaster. The results show important patterns related to:

* **Gender and Survival Rate**
* **Passenger Class and Survival Probability**
* **Age and Survival**
* **Passenger Demographics**
* **Survival Patterns and Trends**

The project demonstrates how **Exploratory Data Analysis (EDA)** and **Data Visualization** can be used to extract meaningful insights from raw data.
